# Nexus Ops Docs

Dokumentasi Capstone Project 50 Team B 2026 — Docusaurus + Bun.

**Live:** https://capstone-project-team-b-2026.github.io/docs/

Mirror publik (diisi Deploy backend / sync tokens):

- [`static/openapi.json`](./static/openapi.json) — kontrak API untuk `npm run api:sync` di web/mobile
- [`static/tokens.json`](./static/tokens.json) — design tokens

## Local

```bash
bun install
bun start
```

Build:

```bash
bun run build
bun run serve
```

## Menambah dokumen

Taruh file `.md` / `.mdx` di folder `docs/`. Sidebar **autogenerated** dari folder itu (`sidebars.ts`).
